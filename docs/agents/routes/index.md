# Routes

Routes fall into two categories: **resource routes** used by SPA pages (HTML redirect + `.json` data endpoints), and **utility routes** that are pure API endpoints called by the frontend in the background (no HTML template flow).

- [Resource Routes](resource-routes.md) — Home, Categories, Items, Kinds, Admin — Users, Forbidden, Authorizations.
- [Utility Routes](utility-routes.md) — Session, Device Authorization, User Navigation Data, Form Support, Subscriptions, Disabled/Pending Cleanup.
